Native image generation in chat

A model and a chat turn must both opt in before Coddy requests the provider's native image tool.

1. Opt in

models[].image_generationEnable the model in settings, then turn on Images in the composer. The enabled send carries metadata.image_generation.

2. Request

OpenAI / Codex ResponsesAdmission checks the effective model and provider. OpenAI API-key and Codex chat providers may receive the native image_generation tool; image generation on direct model requests is refused.

3. Validate and save

Session assetsCoddy validates the image bytes, format and dimensions. It saves the image as a session asset, with a thumbnail when available, and links it to the assistant message.

4. Show in chat

Live and after reloadassistant_images delivers the live update over SSE. Reload reads the assistant message and its asset URLs from the session.

Generated images are not automatically replayed as visual context in later prompts. For an edit, download and reattach the image with a multimodal model. Live Codex entitlement remains unverified.
