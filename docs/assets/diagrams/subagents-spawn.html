What happens on spawn_agent

Every step can refuse with a tool error that names its key; only past the last one does a child session start, as a task of the parent's background pool.

1. Which definition

Lowest priority first; a later folder takes over a name. Project scope means at or under the workspace.

general, explore, crossreview builtin
~/.agents/agents user
${CWD}/.agents/agents project
${CODDY_HOME}/agents user
${CWD}/.coddy/agents project
each subagents.dirs entry either
One immutable Definition name, scope, path, SHA-256 digest; the file is read once and every later step decides on this value
Project files: subagents.project_trust
deny: project folders are never read
ask (default): needs a receipt
allow: trusted like user scope

A receipt in <home>/subagents-trust.json binds project, name and digest.

4. The run

<sessions root>/sess_<parent>/ background/bg_3/ the task, kind agent subagents/sess_9f1c…/ the child, an ordinary sess_ id session.json subagentRun, parentSessionId
foreground (default) the tool call blocks; the result is <subagent status turns> with the report
background returns bg_3 at once; notify_on_finish (on by default) wakes the parent where a waker runs
SubagentStop hooks see status and report
Retired: its tasks stopped, MCP closed, an empty worktree removed; the transcript stays read-only

5. A child's permission prompt

the child's gated tool call stamped with the child's own mode
spawning turn still running: the parent's client under the parent session, titled [subagent <name>], allow or reject only; one prompt per parent at a time
turn ended: DetachedPermissionBroker a prompt still on screen when the turn ends moves here too
console: its permission modal
coddy serve: serve.Runtime asks every surface at once web chat, --remote console, Telegram or Pachca chat; the first answer wins, the other copies go
no broker (coddy acp, print mode, scheduler): refused at once, with a reason

6. resume a finished run

{"agent": "general",
 "resume": "bg_5",
 "prompt": "Go on from where you stopped."}
  • decided like a new spawn, against the definition as it is now; no earlier grant carries over;
  • the child session is reopened from its bundle, the prompt is its next message, the run is a new task bg_… on the same sess_…;
  • a call left without a result is answered as having no recorded result;
  • refused for a run still in flight, another agent name, a moved workspace, a transcript not on disk, the memory child.
