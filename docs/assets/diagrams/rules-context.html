4. Delivered once

  • A document reaches the model once per rules generation, known by DocKey: its real path, links resolved, case folded on Windows and macOS. A session opened in ~/.coddy reads its pair once.
  • A nested document the system message carries already (through instructions.files, or a link) is not attached again, and an instructions.files entry naming a document of the layers adds nothing.
  • A rule still in the window the provider is sent, with the same text, is not attached again. After a compaction folds it away, or once its file changed, the next match brings it back, current.
  • A call that reads or writes a rule document itself does not get it back as a rule.
  • run_command activates nothing, and a folder a call lists or searches brings no glob rule.
  • A template without {{.Rules}} gets no path rules; the documents come whatever it prints.

A provider caches a request by its prefix, and the system message opens every request: one changed byte there throws away the cached conversation behind it. A compaction rewrites that history anyway, so it is the moment to read the files again.
