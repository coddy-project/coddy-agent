# Ваше первое расширение на JavaScript

Создайте страницу со счётчиком, упакуйте её в один ZIP и включите в Coddy. Для создания архива нужен Python, а для запуска - работающий веб-интерфейс Coddy через HTTPS или localhost. Node.js и вызов модели не нужны.

## Создайте два файла

Создайте папку с `manifest.json` и `main.js`. Полные файлы находятся в [examples/extensions/first-extension](../../../examples/extensions/first-extension/).

`manifest.json` задаёт сведения о пакете и его модуле.

```json
{
  "api": 1,
  "id": "first-extension",
  "name": "My first extension",
  "version": "1.0.0",
  "ui": { "entry": "main.js" }
}
```

`main.js` экспортирует функцию, которую Coddy вызывает после одобрения пакета.

```js
export function activate(coddy) {
  const page = coddy.ui.registerPage({
    id: "counter",
    title: "My first extension",
    mount(element) {
      let count = 0;
      const button = document.createElement("button");
      button.textContent = "Clicked 0 times";
      button.addEventListener("click", () => {
        button.textContent = `Clicked ${++count} times`;
      }, { signal: coddy.signal });
      element.append(button);
      return () => button.remove();
    }
  });
  return () => page.remove();
}
```

Страница появляется в меню **Расширения**. Coddy вызывает `mount`, когда вы её открываете, и функцию очистки, когда закрываете. При каждом открытии счётчик начинается с нуля. `coddy.signal` завершает работу обработчиков событий и запросов SDK при остановке расширения. Храните зависимости внутри модуля; относительные импорты не работают с его blob URL.

## Упакуйте и включите

Выполните команду внутри папки с двумя файлами.

```sh
python -m zipfile -c first-extension.zip manifest.json main.js
```

Откройте **Настройки → Расширения**, нажмите **Установить ZIP** и выберите `first-extension.zip`. После установки расширение выключено. Проверьте название и хеш, нажмите **Включить**, затем **Принять риск и включить**. Страница перезагрузится. Одобренный код получает доступ к чатам, учётным данным, API сервера и сервисам, доступным с сервера Coddy; вы включаете его на свой страх и риск.

Откройте **Расширения → My first extension** и нажмите кнопку. На ней должна появиться надпись `Clicked 1 times`. Закройте страницу и откройте снова; надпись должна вернуться к `Clicked 0 times`.

## Добавьте сетевой вызов

В асинхронном обработчике интерфейса вызывайте `coddy.net.fetch`, чтобы обратиться к сервису с сервера Coddy без заголовков CORS на целевом сервисе.

```js
const response = await coddy.net.fetch("http://127.0.0.1:8080/api/status", {
  signal: coddy.signal
});
if (!response.ok) throw new Error(`HTTP ${response.status}`);
const status = await response.json();
```

Сначала запустите свой API по этому адресу или замените URL адресом своего сервиса. `localhost` относится к серверу, на котором работает Coddy. [Пример Local API](../../../examples/extensions/local-api/main.js) содержит поле URL, запросы GET/POST и отмену. HTTP-ошибки целевого сервиса возвращаются как ответы; при сетевых ошибках и ошибках прокси промис отклоняется. Метод поддерживает HTTP(S), загружает ответ целиком и возвращает перенаправления без перехода по ним. Заголовки и ограничения описаны в [контракте сетевого API](../features/extensions.md#http-запросы-с-сервера). Обработчики `transform` входящего потока должны оставаться синхронными; внутри них читайте сетевые данные из кеша.

## Измените или удалите расширение

После правки файлов удалите установленный пакет, создайте ZIP заново, установите его и одобрите новый хеш. Существующие идентификаторы нельзя перезаписать. Чтобы остановить расширение, нажмите **Выключить и перезагрузить** в разделе **Настройки → Расширения**.

Если страница не появилась, проверьте, что файлы находятся в корне ZIP, пакет включён, а `activate` экспортируется. Ошибки активации появляются в настройках. Используйте HTTPS или localhost, чтобы Web Crypto проверял хеш точки входа. Дальнейшие возможности описаны в [руководстве по API](../features/extensions.md) и [указателе примеров](../../../examples/extensions/README.md).
