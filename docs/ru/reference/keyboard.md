# Клавиатура

Клавиши TUI консоли и поля ввода веб-интерфейса в том виде, в каком их назначает код. Таблица консоли составлена по `external/cli/app.go` и `external/cli/tui/editor.go`, таблица веб-интерфейса - по `external/ui/src/ui/chat/Composer.tsx` и компонентам, которые он открывает. Свою краткую версию консоль печатает по команде `/hotkeys`.

## Консоль

Клавиши разбираются в нотацию `ctrl+x` / `shift+enter` / `alt+backspace` из `external/cli/tui/keys.go`. Пока открыто модальное окно, клавиатуру видит только оно; пока открыто меню подсказок редактора, клавиши навигации сначала получает меню.

| Клавиша | Действие |
|---|---|
| enter | отправить, если агент свободен; во время хода поставить в очередь в режиме `agent.queue_mode` (при первом использовании консоль спрашивает режим по умолчанию) |
| shift+enter / ctrl+j | новая строка (обратная косая черта прямо перед enter тоже разбивает строку - для терминалов, которые не сообщают о shift+enter) |
| escape | закрыть меню подсказок, если оно открыто; иначе остановить выполняющуюся команду `!!`; иначе прервать текущий ход (`HandleSessionCancel`) |
| ctrl+c | очистить редактор; в пустом редакторе два нажатия в пределах 2 с завершают работу |
| ctrl+d | выйти, если редактор пуст |
| ctrl+l | окно выбора модели |
| F1 | встроенная документация ([Встроенная документация](../features/built-in-docs.md#справка-в-консоли)); `/docs`, если терминал оставляет F1 себе |
| ctrl+p / ctrl+shift+p | переключать настроенные модели вперёд / назад |
| shift+tab | переключать уровень рассуждения (у моделей с `reasoning_levels`) |
| ctrl+o | развернуть подсказки заголовка, вывод последнего инструмента (живой черновик, пока аргументы `write` / `edit` / `apply_patch` ещё приходят потоком) и последний блок `!!` |
| ctrl+t | свернуть или развернуть блоки размышлений |
| up / down | история промптов на первой / последней строке черновика; иначе перемещение курсора |
| tab | во время хода, если есть черновик и меню подсказок закрыто, поставить в очередь в режиме, противоположном режиму Enter; иначе открыть дополнение или вставить табуляцию |
| 1 / 2 | только пока в строке состояния стоит вопрос первого использования очереди - сохранить Steer / After turn как режим Enter и поставить сообщение в очередь; escape возвращает черновик |
| `/` в начале черновика, `@` в любом месте | открыть меню команд и меню упоминаний по мере ввода ([Упоминания](../features/mentions.md#в-консоли)) |
| tab / enter | при открытом меню упоминаний выбрать подсвеченную строку; папка или `@session:` оставляет меню открытым и показывает своё содержимое |
| escape | при открытом меню упоминаний закрыть его |

Внутри оверлея `/tasks` ([Фоновые задачи](../features/background-tasks.md#в-консоли)).

| Клавиша | Действие |
|---|---|
| up / down | перейти между задачами |
| enter | открыть задачу под курсором - её команду и последние строки вывода |
| s | остановить задачу под курсором или открытую задачу, если она ещё выполняется |
| r | заново прочитать задачи и вывод открытой задачи |
| escape | выйти из открытой задачи; в списке закрыть оверлей |

Внутри справки, которую открывают F1 и `/docs` ([Встроенная документация](../features/built-in-docs.md#справка-в-консоли)).

| Клавиша | Действие |
|---|---|
| буквы, backspace | править строку поиска (в списке) |
| up / down | перейти между пунктами; на странице прокрутить на строку |
| enter | открыть пункт на его разделе; на странице прокрутить на строку |
| pgup / pgdn / space | прокрутить страницу на экран |
| home / end | начало / конец страницы |
| tab / shift+tab | следующий / предыдущий раздел страницы |
| n / p | следующая / предыдущая страница документации |
| / | со страницы вернуться к поиску |
| escape | выйти со страницы; в списке закрыть справку |
| F1 / ctrl+c | закрыть справку |

Клавиши редактирования внутри черновика.

| Клавиша | Действие |
|---|---|
| left / ctrl+b, right / ctrl+f | на один символ |
| alt+left / ctrl+left / alt+b, alt+right / ctrl+right / alt+f | на одно слово |
| home / ctrl+a, end / ctrl+e | в начало / конец строки |
| backspace, delete | удалить один символ назад / вперёд |
| ctrl+w / alt+backspace | удалить слово перед курсором |
| alt+d / alt+delete | удалить слово после курсора |
| ctrl+u, ctrl+k | удалить до начала / конца строки |

Меню, окна выбора и запросы.

| Клавиша | Где | Действие |
|---|---|---|
| up / down | меню подсказок, любое окно выбора | переместить подсветку |
| enter / tab | меню подсказок | применить подсвеченную строку; enter на слэш-команде применяет её и сразу отправляет, поэтому `/resume` + enter открывает выбор сессии напрямую |
| escape | меню подсказок | закрыть его |
| набранные символы, backspace | окна выбора модели, режима, темы и сессии для возобновления | фильтровать список |
| enter | окно выбора, запрос разрешения, вопрос | выбрать подсвеченный вариант (запрос разрешения предлагает варианты, которые прислал агент) |
| escape / ctrl+c | окно выбора, запрос разрешения, вопрос | отменить; отменённый запрос разрешения отклоняет вызов |
| space | вопрос с `multiple: true` | переключить подсвеченный вариант |
| escape | редактор своего ответа на вопрос | вернуться к списку вариантов |

Замечания о платформах из кода. Одиночный Escape распознаётся через 10 мс локально и через 100 мс, если задана `SSH_CONNECTION` или `SSH_TTY` (`external/cli/tui/terminal.go`); новая строка через обратную косую черту и enter нужна терминалам, которые не сообщают о shift+enter; `ctrl+c` в непустом редакторе очищает его, поэтому для выхода нужны пустой редактор и второе нажатие.

## Веб-интерфейс

Поле ввода - обычная `textarea`; клавиши, которых нет в списке, сохраняют своё значение в браузере.

| Клавиша | Где | Действие |
|---|---|---|
| Enter | поле ввода, любое устройство с клавиатурой, в том числе узкое окно | отправить, если агент свободен; во время хода поставить текст и вложения в очередь в настроенном режиме `agent.queue_mode` (при первом использовании интерфейс спрашивает, какой режим предпочесть) |
| Tab | поле ввода во время хода, если есть черновик и пикер закрыт | поставить текст и вложения в очередь в режиме, противоположном предпочтению для Enter |
| Shift+Enter | поле ввода | новая строка (поведение браузера по умолчанию, не перехватывается) |
| Ctrl+Enter / Alt+Enter | поле ввода | новая строка в позиции каретки с заменой выделения (браузеры её не вставляют, поэтому это делает поле ввода) |
| Cmd+Enter | поле ввода | отправить, как Enter |
| Enter | поле ввода, устройство только с сенсорным вводом (нет указателя с наведением, указатель грубый, то есть телефон) | новая строка; отправка выполняется кнопкой, потому что на клавиатуре телефона нет Shift+Enter |
| Enter, Tab, стрелки, Escape, Ctrl+Z | поле ввода, пока метод ввода составляет текст (keydown несёт `isComposing` или, в Safari, keyCode 229 в пределах 100 мс после `compositionend`) | принадлежат методу ввода - ничего не отправляется, ни один пикер (слэш-команд, `@`, опций команды или диапазона строк) не выбирает строку, не двигает подсветку и не закрывается, а Ctrl+Z не возвращает черновик, каким он был до "Улучшить промпт"; любой другой keyCode 229, который клавиатуры Android шлют для обычных клавиш, работает в пикерах как обычная клавиша, хотя Enter с ним всё равно не отправляет |
| ArrowUp / ArrowDown | открыто меню слэш-команд, `@` или опций команды | переместить подсвеченную строку с переходом через оба конца списка |
| Tab | открыто меню слэш-команд | применить подсвеченную команду |
| Tab | открыто меню упоминаний `@` | применить подсвеченную строку, в том числе во время хода |
| Tab | открыто меню опций команды (`/compact --model`, `/goal -r`) | вставить подсвеченную опцию, модель или уровень рассуждения в черновик |
| Enter | открыто меню слэш-команд, `@` или опций команды | применить без отправки; строка папки или схемы оставляет меню `@` открытым, а `--model` открывает список моделей |
| Escape | открыт пикер слэш-команд, `@`, опций команды или диапазона строк | закрыть пикер; пикер `@path:N-M` для этого упоминания остаётся закрытым, пока черновик не уйдёт дальше |
| Escape | открыта всплывающая панель с разбивкой контекста | закрыть её |
| Escape | поле ввода развёрнуто поверх чата | свернуть его до высоты текста; следующий Escape выходит из правки, если она открыта ([Веб-интерфейс](../surfaces/web-ui.md#длинные-промпты-в-поле-ввода)) |
| Ctrl+Z / Cmd+Z | поле ввода сразу после "Улучшить промпт" | восстановить черновик, каким он был до улучшения, один раз |
| Enter / Space | фокус на кнопке кольца контекста | открыть или закрыть разбивку |
| Enter / Escape | фильтр меню моделей (показан, если бэкендов больше пяти) | выбрать первое совпадение / закрыть меню |
| Escape | меню поля ввода ("Режим", "Модель", "Рассуждение", "Разрешения"), меню окружения, папки или ветки | закрыть его, где бы ни был фокус |
| Escape | окно выбора папки ("Открыть папку…") | свернуть строку новой папки, если она открыта, иначе закрыть окно, как это делает "Отмена" |
| Escape | поиск для установки скилов в разделе "Навыки" настроек, с набранным запросом | очистить его и убрать результаты маркетплейса; следующий Escape достаётся выдвижной панели |
| Escape | экран, открытый с боковой панели, - "История", "Планировщик", "Рой" поверх чата, "Документация", "Настройки" | закрыть его, как кнопка ×, и вернуться к тому, что было под ним; по одному шагу за раз - сначала закрываются открытое задание планировщика или его запуски, открытая строка настроек и раздел настроек на телефоне или планшете, а открытое меню, пикер, подсказка или список комбобокса либо поиск с текстом получают клавишу раньше экрана ([Веб-интерфейс](../surfaces/web-ui.md#раскладка)) |
| Enter | окно вопросов | отправить ответ, когда на каждый вопрос есть ответ; нажатие в поле ввода по-прежнему относится к полю ввода |
| Escape | окно вопросов | пропустить вопросы, если поверх чата не открыт экран боковой панели и клавишу не забрал пикер поля ввода |
| Escape / Tab | диалог подтверждения | отменить / удерживать фокус внутри диалога |
| Ctrl+Shift+F / Cmd+Shift+F | открытый чат, включая поле ввода | открыть окно "Файлы" или закрыть его ([Веб-интерфейс](../surfaces/web-ui.md#файлы-рабочей-папки)) |
| Escape | окно "Файлы" | очистить фильтр, если в нём есть текст, иначе закрыть окно; док под ним остаётся до следующего Escape |
| Escape | окно "Правки" | убрать меню ⋮, если оно открыто, очистить фильтр дерева, если в нём есть текст, иначе закрыть окно; если открыт вопрос об отмене правок, ответить на него, а окно не трогать ([Веб-интерфейс](../surfaces/web-ui.md#окно-правок)) |
| F1 | где угодно | открыть окно документации или закрыть его ([Встроенная документация](../features/built-in-docs.md#окно-документации-в-веб-интерфейсе)) |
| / | окно документации, вне поля ввода | поставить курсор в его поле поиска |
| ArrowUp / ArrowDown, Enter, Escape | поле поиска документации | переместить выбранный результат, открыть его на его разделе, очистить поиск; в пустом поле Escape закрывает окно документации |

У остановки хода нет клавиши - для этого есть кнопка "Остановить генерацию" на панели поля ввода. Меню `@` открывается, когда вы набираете `@` ([Упоминания](../features/mentions.md#в-веб-интерфейсе)), а `:` после файла превращает его в выбор диапазона строк; ни то, ни другое не назначено на клавишу.
